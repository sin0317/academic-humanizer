## 一、中文：按病灶分类的词表

### 1.1 拔高与意义（学术稿最致命，因为它同时是过度主张）
至关重要、核心关键、关键性作用、具有重要意义、重大而深远、战略意义、里程碑、填补空白、
奠定基础、提供参照、提供范式、提供样板、贡献了智慧、不可或缺、深远影响、开启了新篇章、
标志着、见证了、是……的体现/证明、凸显/彰显……意义、为……注入新动能

### 1.2 万能动词（无主语无对象）
赋能、助力、夯实根基/底座、锚定目标、聚焦主线、彰显担当、提质增效、蝶变、跃升、
统筹推进、一体化推进、不断完善、持续提升、全面加强、有效衔接、深度融合、系统构建
> 判定：删掉这个词，句子的事实信息是否减少？不减少就是空词。

### 1.3 伪深度动词
深入探讨、深入剖析、深入揭示、系统梳理、精准识别、厘清、勾勒、阐释、解构、重塑、
透视、观照、把脉、破题
> 判定：能换成"分析/比较/检验/计算/统计/访谈"的，就换。

### 1.4 抽象名词（图景类）
格局、图景、图景式、版图、谱系、脉络、逻辑、范式、路径、机制、体系、闭环、生态、
底色、基因、密码、密钥、引擎、底座
> 判定：这些词单独出现不算错，**连续三个以上出现在同一段**就是 AI 味。

### 1.5 连接词（中文检测器三家全敏感）
首先 / 其次 / 再次 / 最后、一方面 / 另一方面、此外 / 与此同时 / 另外、综上所述 / 由此可见 /
总而言之、值得注意的是 / 需要指出的是 / 不难发现、毋庸置疑 / 显而易见、在此背景下 /
随着……的快速发展 / 近年来（无具体年份）、基于此 / 据此（滥用时）

### 1.6 判断动词（句式单一的元凶）
表现为、呈现出、体现出、构成了、形成了、印证了、折射出、昭示着、意味着（空用）

### 1.7 四字标语与对仗
刚性守安全、文化促长效、数量守底线、质量强生产、以点带面、点面结合、条块联动、
上下贯通、左右协同、内外兼修、标本兼治、源头治理、系统治理、综合治理
> 学术稿里出现四字对仗，八成是把结论压成了口号。

### 1.8 模糊量词
多项、若干、一大批、一定程度上、相对较为、总体而言、在很大程度上、某种意义上、
部分学者、有研究认为（无引文）、大量研究表明（无引文）

### 1.9 程式化句式（整句模板）
- 摘要八股：`本文综合运用[A]、[B]与[C]，系统识别[X]、[Y]与[Z]，检验[M]，进而构建[N]，并据此提出[P]，可为[Q]提供参照。`
- 综述罗列：`[作者]等提出了[方法]；[作者]等提出了[方法]；……`
- 理论排比：`[X]理论揭示……；[Y]理论强调……；[Z]理论主张……`
- 拔高尾巴：`实证结果印证了……的工作要求`、`为……提供了现实支撑`、`为……提供参照`
- 政策排比：`政策上应完善……，并选取……，并探索……`
- 空泛收尾：`构成……格局`、`形成……正向循环`、`构建可持续的……体系`
- 分类机械展开：`[四位一体/五大基因/三维体系]` + 每类同句式一段

### 1.10 通用模式补遗（论文里也会出现）

**知名度/媒体式**：引起广泛关注、受到学界高度重视、被多家媒体报道、广受好评、备受瞩目
**-ing 拖尾（中文形态）**：，彰显了…、，体现了…、，确保了…、，反映出…、，印证了…、，标志着…
**广告式**：开创性、领先、卓越、丰硕成果、亮点纷呈、成效显著、卓有成效
**无引文归因**：有研究认为、大量研究表明、学界普遍认为、多数学者认为、相关研究指出
**挑战与展望提纲**：仍面临…挑战、未来可从…方向展开、有待进一步研究（无具体所指时）
**回避系词**：作为…的重要组成部分、扮演着…角色、构成了…的基础、发挥着…功能
**虚假范围**：从…到…（两端不同尺度）、全链条、全周期、全方位覆盖
**通用积极结论**：前景广阔、应用前景广阔、具有重要推广价值
**对话残留**：希望对您有帮助、如需修改请告知、以下是修改后的版本、截至我的知识截止日期、这是个很好的问题

## 二、英文：AI 词汇与短语

### 2.1 高频 AI 词（Layer 1）

## 三、结构模式（真正被激进档检测器盯的东西）

| 结构 | 中文形态 | 英文形态 | 处置 |
|---|---|---|---|
| **统计分组对称** | 优/高/中/低四并列 + %；①②③ 枚举；重点/关注/一般三对称；四区各一句 | four-way split with percentages; ①②③ list; three parallel tiers | 改"有主次、长短交错"的叙述，**数字全留** |
| **分类机械展开** | 四位一体 / 五大基因 / 三维体系，每类同句式 | three-pillar framework, each described identically | 打破对称，允许长短不一，用例子替代定义 |
| **串行动词链** | 构建—梳理—识别—厘清—揭示（五个平行动词一口气） | identify, analyze, and demonstrate（+4 more） | 改成主谓清楚的长短句，允许"并""了""得出结论认为" |
| **均匀长句** | 每句 20–30 字，段落 150–200 字 | every sentence 25–35 words | 拆短，制造长短交错 |
| **否定式排比** | 不仅是……更是…… / 不只是……而是…… | not just X, but Y | 拆成两句，去掉转折壳 |
| **三段式强迫** | 一是…二是…三是… / 分三点论述 | rule of three everywhere | 改两项或四项；真有五项就写五项 |
| **内联加粗标题** | **标题：** 正文 | **Bold label:** body | 改连续行文（申请书 run-in 标题除外） |
| **破折号揭示** | ……——这正是…… | ...—which is exactly... | 英文删净；中文每千字 ≤2 |
| **空泛包裹数据** | 数据周围全是"统筹推进/协同保护/全面加强" | numbers wrapped in "comprehensive framework" | 拆包裹，数据一字不删 |

**判定顺序**：先看结构对称（3 处以上并列且句式等长 → 必改），再看词（词只影响精细度，结构决定检测器判定）。

## 五、伪信号：看着像 AI 腔，其实是学科规范（别改）

| 表达 | 为什么不是 AI 腔 |
|---|---|
| P<0.01、β=0.42、95% CI、OR=1.8 | 统计报告规范，必须保留 |
| per-protocol、intention-to-treat、double-blind | 方法学固定术语 |
| "样本按总蛋白归一化"（被动、无施动者） | 施动者无关，被动合法 |
| "the results suggest / 结果提示" | **有证据的对冲**，改成 prove/证明就是造假 |
| "本文认为""我们认为" | 学术写作标准主语 |
| 分号、偶尔三项并列 | 适度使用是正常文风 |
| 公式、伪代码、参数表、变量符号 | 任何检测器都不把它当文本特征 |
| 参考文献条目 | 见 references 第七节，假阳性，不改 |
| 长表格里的等长单元格（"优/良/中/差"） | 表格本就整齐，检测器不看表格 |
| 政策文件名、标准号（GB/T 9704-2012） | 专名，保留原样 |
