# 中文送审检测器校准档案

> 本文支撑 `SKILL.md` §5 与规则 W（统计分组对称）、V（参考文献假阳性）、X（知网）、Y（万方）、Z（维普）。
> 所有样本已脱敏：不出现作者姓名、单位、论文题目、来源署名，仅保留可复现的数值与结构结论。

---

## 一、首要规则：结论不可混用、不可互证

同一篇文本在不同检测器下 AI 率可差数倍，**且标注片段几乎不重叠**。所以：

- 不拿"某平台 20% 通过"去推断另一平台；
- 不拿"两个平台都判高"当相互印证（可能命中不同维度）；
- 改写只认**目标机构所用的那一款**报告的标注片段。

**跨平台反证（硬数据）**

| 对照 | 数值 | 说明 |
|---|---|---|
| 同一篇论文：知网 vs 维普 | **3% vs 67%**（差 64 点） | 维普按句式工整度拆段，连纯手写致谢、英文摘要都被标；知网经语义逻辑判为人工写作 |
| 同一篇算法定义密集硕论：万方 vs 知网 | **56% vs 21%**（差 35 点） | 算法定义被万方统计特征模型识为 AI，知网经知识溯源判为领域通用表述放行 |
| 同一篇纯 AI 记者稿：知网 vs 维普 vs PaperPass | 37% / 46.1% / 69.1% | 同一文本三平台各自为政 |
| 同一作者同一篇，无改动半小时复测（知网） | 71.2% → 18.4% | 波动 52.8 点，报告时效极短 |

## 二、四档敏感维度模型

| 档位 | 检测器 | 盯什么 | 典型正文 AI 率 |
|---|---|---|---|
| 激进档 | 朱雀 / BestPaper / 论文狗 | **密集空泛 + 结构对称**的句式密度 | 71–83%（同稿三档互证） |
| 中等档·模板凶 | 万方（文察/智搜） | 模板化 / 定义类 / 算法描述 / 摘要八股 / 标准学术用语 | AI 辅助 45–69%；重度模板 85% |
| 中严档·规整凶 | 知网（AIGC 3.0+） | 写作逻辑高度规整的人类原创综述 / 推导 / 定义 | 纯 AI 37–78%；AI 辅助 21–45%；手写规整 29–47%；纯人工 2–3% |
| 中等档·句式凶 | 维普（斟知/大学生论文管理系统） | 均匀长句 / 连接词密集 / 段落对称 / 整齐排比 | 纯 AI 75–95%；AI 辅助 47–72%；波动极大 |

**2026 通用阈值**：本科 ≤30% / 硕士 ≤20%（维普部分学院 15%）/ 博士 ≤10% / 期刊 ≤25%（维普社科 ≤20%、自然版 ≤12%）。超 50% 多直接退稿或取消资格。

## 三、激进档：触发的是对称，不是数据

### 3.1 同一统计型稿件三档互证（约 8000 字，31.7% 句子带具体数字/年份）

| 检测器 | AI 率 | 标注特征 |
|---|---|---|
| BestPaper | **78.15%**（42 段 High / 91 段） | 统计分组对称段：优/高/中/低四并列+%、①②③ 枚举、三对称；另 8 条参考文献被标 88–98% |
| 腾讯朱雀 | **82.51%**（其中 20.96% 为高置信 AI 特征） | 片段 2（统计分组对称）**0.9966** vs 片段 4（数据密集但叙述化）**0.2560** |
| 论文狗 | 全文 **47.63%** / 正文 **71.08%** | 逐段峰值：案例剖析 100%×3、治理响应 100%、空间分异 81.09%、关键制约 76.89%；参考文献/作者简介/关键词未标高疑似 |

**结论**：每一个 80%+ / 100% 的高分段都精确对应一个「统计分组对称」结构；数据最密但展开成叙述的段落反而降级。

### 3.2 同一文档"人性化前/后"对照（最强证据）

同一篇论文的改写前后两版，BestPaper 检测时间相差 17 分钟：

| 版本 | AI 率 | 显著疑似 |
|---|---|---|
| 改写前（19,149 字） | **54.51%** | 44 段 High，几乎全文（引言/理论/文献/历史/基因/实证/政策/结论）+ 参考文献 |
| 改写后（20,655 字） | **3.37%** | 0 段正文；唯一 High = 一条引文（91.06%，假阳性） |

**两版保留同一批数据**（面积数字、目标年份、GIS、地名）——被标的是数据外面那层空泛对称包裹，不是数据。改写只是把包裹拆开。

### 3.3 可复用的四类改写动作

1. **拆串行动词链**：`构建/梳理/识别/厘清/揭示` 五连 → 改为"对 X 进行了…、并找到了 Y、弄清楚了 Z"的长短交错。
2. **去空泛副词与四字标语**：高度重视 → 十分重视；牢牢守住 → 坚守；深度转型 → 转变。
3. **展开口语化、破对称**：`素有…美誉` → `有着…的美称`；`要求以…为总抓手层层压实` → `提出要依靠…这一总抓手来落实`；`统筹推进…协同保护` → `全面加强…以及…各方面`。
4. **数据保留、只拆包裹**：数据一字不删，删的是它周围的并列句。

## 四、知网（中严档·对规整的人类写作敏感）

### 4.1 证据

| 样本类型 | 知网 AI 率 | 关键对照 |
|---|---|---|
| 纯 AI 长文（公开报道样本） | 37% | 同篇维普 46.1%、PaperPass 69.1% |
| 同上，同作者两篇无改动复测 | 71.2% → 18.4% | 半小时内波动 52.8 点 |
| 算法定义密集硕论（第三方实测） | 21%（合规） | 同篇万方 56%（高风险） |
| 高校硕士讨论部分（自查） | 42% → 8% | 逐句调逻辑 + 补实验推导后达标 |
| 财务管理本科 1.7 万字（实测） | 41.6% → 5.1% | 标红集中"理论基础/指标分析"；财务报表数据表未标红 |
| **机械硕士 1.1 万字全文手写零 AI（实测）** | **整体 29%** | 文献综述 41% / 公式推导 47% / 理论定义 35% / 案例分析仅 8% |
| 文学硕士 1.25 万字 DeepSeek 初稿 | 68.3% → 12.1% | 同篇维普 14.2%、万方 10.8% |
| 3.0 升级前后（5 篇不同 AI 率） | 纯 AI 72→89 / AI+简改 45→63 / AI 辅助 21→38 / 少量润色 8→16 / 纯人工 2→3 | 升级对 AI 生成识别精度 +15~18 点，纯人工影响极小 |

### 4.2 要点

- **误判重灾区 = 太规范**：文献综述、理论定义/概念阐释、公式推导、实验步骤、教科书式描述。同一作者手写零 AI 仍判 29%，差近 40 点只因章节类型不同——**误判与内容类型强相关，与是否真用 AI 关系不大**。
- **易标红词/结构**：首先/其次/再次、一方面/另一方面、综上所述/由此可见、随着…快速发展、在此背景下、段落长度均匀（150–200 字）、参考文献格式过于规范统一。
- **标红机制**：连续 **13 字符**以上匹配 AI 特征即标黄；片段置信度 80+ 确认 / 50–80 疑似 / <50 原创；报告含「AI 生成内容占比」总指标。
- **波动**：同篇同平台波动 5–10% 正常（极端 12.3%）；算法静默升级可让同篇无改动 22%→45%；**报告有效期短，提交前 1–2 周复测**。
- **宽容项**：统计分组对称（W）一般不触发；数据表、带具体数字的实证段通常不标红；参考文献一般不计入。
- **改写动作（经报告验证可把 40%+ 压到 5–8%）**：综述每引 2–3 篇插一句自己的判断、推导/实验补具体操作细节、标准概念换自己的话转述、长短句交错、删/换标准连接词、加个人研究经历。

## 五、万方（中等档·对 AI 典型模板最凶）

### 5.1 证据

| 样本类型 | 万方 AI 率 | 关键对照 |
|---|---|---|
| 深度学习硕论 2 万字 | **69.7% → 7.2%** | 标红集中"模型结构阐述/相关工作"；伪代码/公式/实验表格未标红；"XX 等人提出了…"句式重灾区 |
| 综合稿 8200 字 | **45.3% → 5.1%** | 文献综述 67.8→6.3 / 模型构建 38.2→4.8 / 实证 32.1→3.9 / 结论 51.6→7.2 |
| 管理学硕论 8500 字 | **63.4% → 5.8%**（同篇知网 6.4%） | 跨学科多组：教育学 45→5 / 公管本科 50→7.5 / 文学 58→6.5 / 经济学 52→7.8 |
| DeepSeek 生成 + 自改稿 | **文察 85%**（学校 ≤30%） | 摘要 94 / 文献综述 92 / 结论 90 全红 |
| 算法定义密集硕论同篇 | **56%（高风险）vs 知网 21%（合规）** | 直接证伪"万方=温和档" |

### 5.2 要点

- **绝非温和档**：对模板化/定义类/算法描述/摘要八股/标准学术用语的敏感度**高于知网**。属"中等档、对 AI 典型模板痕迹最凶"。
- **误判重灾区**：① 摘要八股串行动词链；② 整齐排比（首先…其次…再次…最后）；③ 标准学术用语搭配（具有重要意义/为…提供新思路/为…提供参照）；④ 模板化定义与算法描述；⑤ 高度概括、缺具体细节；⑥ 政策建议多重"并…并…"与"形成…格局/循环"空泛收尾。
- **宽容项**：带具体年份/地名/数字的排比、年表、分类标签、统计分组对称（W）、数据表/公式/伪代码。即"凶"针对空泛模板，不针对事实与数据。
- **标红机制**：红(80%+)/橙(50–80%)/黄(30–50%)/绿(<30%) 四级热力图；标红=句式高度统一、用词同质化、无个性化论述、内容模板化，集中在绪论/研究现状/结论；**短段落（500 字内）准确率较低**；2026 版本比去年更严。
- **改写动作（45–85% → 5–8%）**：拆摘要串行链、删拔高尾巴、破"并…并…"排比、换标准连接词与四字标语、把模板化定义/算法描述改为带细节的叙述、补个人观点与具体案例。

## 六、维普（中等档·对句式工整度最敏感、波动最大）

### 6.1 证据

| 样本类型 | 维普 AI 率 | 关键对照 |
|---|---|---|
| 新传硕士 1 万字 DeepSeek 辅助稿 | **55.2% → 8.4%** | 标红集中 20–30 字均匀长句；长短交替后降分 |
| 某章节 560 字"研究意义与创新点" | **87% → 12%**（全文 41%→12%） | 标红=句式统一工整、长句均匀 |
| 某稿 3500 字 | 68.2% → 11.7% | 误差 2.1% |
| 某稿 5000 字 | 72.3% → 8.7% | 误差 2.1%；格式保留 |
| 市场营销本科 9832 字 DeepSeek 稿 | **92.3%（各章 88–97%）→ 3.2%** | 纯 AI 稿维普普遍 75–95% |
| **跨平台反证** | **知网 3% vs 维普 67%** | 维普按句式工整度拆段；纯手写致谢、英文摘要被误标 |

### 6.2 要点

- **按 150–200 字拆段扫描「句式工整度 + 连接词密度」**，结合困惑度/突发度判定。对句式结构的敏感度高于知网。
- **误判重灾区**：均匀长句（20–30 字）密集、段落长度对称、连接词密集、整齐排比、摘要八股、标准学术用语、文献综述/公式推导/实验步骤（触发维度是句式而非语义）。
- **宽容项**：带具体事实且长短交错的段落；数据表/公式/伪代码通常不标红。
- **标红机制**：绿(<20%)/黄(20–50%)/红(>50%)，**句子级标注**（比知网段落级更细）；连续 200 字困惑度<30 且突发度<0.2 即判 AI；同篇不同时间波动 1–3 点正常，**定稿前 48 小时内用同版本复测**。
- **改写动作（47–92% → 3–12%）**：核心是破坏句式工整——20–30 字长句拆短、句式错落、删密集连接词、段落对称改为主次叙述、插入个人研究经历与具体案例。

## 七、参考文献假阳性（并非所有检测器共有）

| 检测器 | 对参考文献的判定 |
|---|---|
| BestPaper | 会把参考文献（短、格式统一、无语义变化）标到 **88–98%**；彻底降 AI 版唯一残留 High 即一条引文（91.06%） |
| 腾讯朱雀 | 参考文献+作者简介片段判 **0.0001**，基本不误标 |
| 论文狗 | 参考文献/作者简介/关键词**均无高疑似标注** |
| 知网 / 万方 | 通常不计入 AI 率 |

**操作**：参考文献按目标期刊/学校规范正常排版。**不要**为降 AI 率改写、打乱或删减参考文献——对 BestPaper 改了也常继续被标，还伤学术规范与可追溯性。

## 八、把校准落到改写动作上（四条）

1. **送万方/维普**：清 Q（摘要八股）、R（拔高尾巴）、S（并…并…）、T（空泛结论）+ 模板化/定义类（万方）、均匀长句与整齐排比（维普）。带具体事实的排比、年表、数据表保留。
2. **送知网**：除 Q–T 外，额外清综述/理论定义/公式推导/实验步骤等"太规范"章节里 J/K/L/M/N 的密集堆叠。统计分组对称（W）与数据段不必强行重写。
3. **送朱雀/BestPaper/论文狗**：必须把 J/L/M/N/O/W 的句式架构改成"有主语、长短交错、以具体事例或数据落脚"。目标是**降空泛、破对称、拆包裹**，不是删数据。
4. **"有数据就安全"是误区**：数据被空泛/对称包裹时照样标红；先拆包裹，数据一字不删。
